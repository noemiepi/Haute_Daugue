# 🌭 Haute-Daugue
A single player game where you are a dog named Merguez that recently been put on a diet and you are mad about it. Today, your owner is organising a barbecue where meat is everywhere. \
Your goal? Eat every sausage in sight. \
But be careful! The guests roaming the house will try to stop you from eating as you get longer with every sausage you eat.

## 🎛️ Controls
- **Movement**: WASD or Arrow Keys
- **Run**: LShift or RShift while moving
- **Interaction**: E (when near an interactable object)

## 💾 Installation
Go on release and download the zip file for your OS (Linux or Windows). \
Extract the zip file and:
- open `haute_daugue_the_game.x86_64` for Linux
